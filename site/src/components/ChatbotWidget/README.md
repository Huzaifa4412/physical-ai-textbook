# Chatbot Widget Component

A modern, responsive chatbot widget for the Physical AI Textbook Docusaurus site.

## Features

- Floating chat widget with toggle button
- Real-time messaging interface
- Typing indicators
- Responsive design for all screen sizes
- Dark/light mode support
- Smooth animations and transitions

## Usage

The component is automatically integrated into all pages via the Root theme component.

## Structure

- `ChatbotWidget.js` - Main React component
- `ChatbotWidget.css` - Styles for the component
- `index.js` - Export file

## Styling

The component uses Docusaurus theme variables for consistent styling across light/dark modes.
